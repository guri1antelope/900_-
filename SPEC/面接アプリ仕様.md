# 高志中等 面接アプリ 機能仕様書（SPEC）

## 1. システム概要
ブラウザ単体（HTML/CSS/JavaScript）で動作する、新潟市立高志中等教育学校の入学者選抜向け面接トレーニングWebアプリ。
音声入力・音声合成を用いて面接官と対話し、回答に対する評価や追加質問を行う。

---

## 2. 画面構成
1. **ホーム画面 / モード選択**
   - モード選択:
     - 「練習モード」（優先度S・A・B/Cから各1問、計3問のランダム特訓・その場でフィードバック）
     - 「本番モード」（5〜6問通し面接・最後に総合評価）
   - 音声テスト・マイク設定確認
   - 困ったときのフレーズ確認（緊急対応マニュアル）
2. **面接対話画面（練習・本番共通）**
   - 面接官エリア: 面接官アイコン、発話テキスト表示、音声再生ステータス（波形アニメーション）
   - 受験者エリア: マイク入力状態（待機・録音中・認識完了）、音声認識テキストプレビュー
   - 緊急フレーズボタン:
     - 「もう一度質問をお願いします」
     - 「少し考える時間をください」
     - 「緊張してしまいました。もう一度最初からお話ししてもよろしいでしょうか」
   - 操作ボタン: 「回答完了」「スキップ」「終了」
3. **フィードバック・結果画面**
   - 練習モード: 回答直後にポップアップまたは下部エリアにアドバイスを表示。
   - 本番モード: 全問終了後に総合評価を表示。
     - 良かった点（グッドポイント）
     - 改善のアドバイス（ワンポイント）
     - 観点別チェック（結論ファースト、自立・互恵の視点、自己評価）

---

## 3. 音声モジュール設計（疎結合アーキテクチャ）
将来的なAPI差し替えを見据え、音声機能は抽象化インターフェースとして実装する。

- `VoiceInputService`:
  - `startListening(onResult, onError)`
  - `stopListening()`
  - 現行実装: `WebSpeechVoiceInput`（ブラウザ標準 Web Speech API - `webkitSpeechRecognition`）
  - 将来差し替え候補: Gemini Live / Whisper API等
- `VoiceOutputService`:
  - `speak(text, onEnd)`
  - `stop()`
  - 現行実装: `WebSpeechVoiceOutput`（ブラウザ標準 SpeechSynthesis）
  - 将来差し替え候補: 各種高品質TTS API

## 4. 面接出題・追加質問ロジック
### 4.1 出題優先度
- **優先度S（コア質問 1〜5）**: 本番モードでは必ず3〜4問をここから選定。
  - Q1: 志望理由
  - Q2: 小学校6年間でやり遂げたこと（自立）
  - Q3: 長所と短所（自己評価）
  - Q4: 将来の夢や目標（志の涵養）
  - Q5: 入学後、特に力を入れたいこと
- **優先度A（理念・人物面 6〜12）**: 1〜2問選定。
  - Q6: 自立（自律）への理解と実践
  - Q7: 互恵（互いに助け合うこと）のエピソード
  - Q8: 失敗や悔しかったことの乗り越え方
  - Q9: 周りからどんな人だと言われるか
  - Q10: オープンスクール等の印象
  - Q11: 得意教科と苦手教科への取り組み
  - Q12: 6年一貫校の良さ
- **優先度B（思考力・協調性 13〜17）**: 0〜1問選定。
  - Q13: グループ活動で意見が対立したときの解決法
  - Q14: 気になったニュース・社会の出来事
  - Q15: 尊敬する人
  - Q16: 自分を漢字一文字（または動物）に例えると
  - Q17: 家庭学習の工夫
- **優先度C（状況対応・締めくくり 18〜20）**: 必要に応じて選定。
  - Q18: 緊張や疲れたときのリフレッシュ方法
  - Q19: 通学方法・安全への意識
  - Q20: 最後に言い残したこと・自己PR

### 4.2 追加質問（深掘り）ロジック
- 各質問に定義された「追加の深掘り質問」を保持。
- 回答テキストの長さ・内容を判定し、本番モードでは各セッション中に1〜2回、練習モードでは任意で追加質問を発動。
- 例（Q1 志望理由の場合）:
  - 「高校受験がない6年間を、あなたはどう過ごしたいですか？」
  - 「他の学校とはどこが違うと感じましたか？」
- 例（Q2 やり遂げたことの場合）:
  - 「辛いと思ったとき、何が一番の支えになりましたか？」
  - 「その経験から得た力は、中学校生活でどのように活かせそうですか？」

## 5. フィードバック評価ロジック
回答テキストから以下のポイントをチェックし、アドバイスを生成する。

1. **結論ファースト度**:
   - 冒頭部分に結論（「〜だからです」「〜です」）が含まれているか。
2. **理念・キーワード含有**:
   - 自立・継続・工夫（Q2、Q6、Q8等）
   - 仲間・協力・相談・相手の良さ（Q7、Q13等）
   - 改善・意識（Q3等）
3. **文量・構成**:
   - 短すぎず、かつ長すぎて主旨がブレていないか（目安100〜250文字程度の発話量）。
